O-Form

Push/pull solid modeling · OSAS


About

O-Form is a free Windows 3D modeling application from Human Centric Works. It is a clone of Blender @BLENDER_VERSION@ LTS, kept as its own project with the visible workflow reduced to solid modeling: one active tool, a left tool pane, axis locks, and a measurements box.

O-Form is part of OSAS, the Open Source Architecture Suit. It is not affiliated with the Blender Foundation or with Trimble. It does not use SketchUp files, icons, or artwork.

O-Form is free and open-source software under the GNU GPL, version 2 or later, the same terms as Blender. Source: github.com/HolagundiWorks/o-form .


Package Contents

This package includes:

• The O-Form application (oform.exe).

• Scripts and add-ons used by the modeling template.

• Readme and copyright files.


Installation (Windows)

Unpack the folder anywhere on your hard drive. Launch oform.exe. Files are saved as .blend. File → Export writes Wavefront OBJ and glTF.
