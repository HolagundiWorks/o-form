# Contributing to O-Form

O-Form is developed by Human Centric Works for OSAS. The repository is a clone of Blender 5.2.3 LTS with a modelling-focused product surface.

**Open Source. Built for Architects. Driven by Community.**

## Before you start

1. Read the [user overview](docs/user/overview.md) and [architecture notes](docs/developer/architecture.md).  
2. Prefer changes under `scripts/startup/bl_app_templates_system/oform/` for product behaviour.  
3. Do not remove or rewrite license texts, `AUTHORS`, or third-party notices.  
4. Do not add a Blender upstream remote or rewrite Git history.

## Pull requests

Use GitHub pull requests against `main` on https://github.com/HolagundiWorks/o-form.

Please include:

- What changed and why  
- How you tested (selftest command and/or manual steps)  
- Whether the change is documentation-only, template Python, or C++/CMake  

This project is **not** the Blender Foundation mirror workflow. Do not open Blender Foundation patches here expecting projects.blender.org review.

## Code of conduct / security

No separate `CODE_OF_CONDUCT.md` or `SECURITY.md` is published in this repository yet. Report security concerns privately to the maintainers via the GitHub organization contact for HolagundiWorks until a security policy is added.

## License

Contributions are expected under the same terms as the file you modify, typically **GPL-2.0-or-later**, consistent with Blender and existing O-Form sources.
