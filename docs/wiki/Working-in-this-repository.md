# Working in this repository

- Change only Myna3D's own files (the `oform` template, branding, docs); do not reformat or refactor Blender sources.
- The tree is about 15 GB, mostly `.git` and `lib/`: scope searches to a path.
- Binaries use Git LFS. `lib/windows_x64` is a submodule that always shows as modified: leave it and never `git add` it.
- Brand: Grove `#166040`, white three-circle mark generated by `MynaUI/tools/Brand`; copy the files, do not redraw.
- Building needs the Blender toolchain (`docs/build/`); say so when you did not build.
- Licensing: Blender's GPL tree stays separate from the suite's own licensing; see `docs/licensing/`.
- Git: add files by name; the default branch is `main`.
