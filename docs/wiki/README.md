# Wiki source

These files are the source of the GitHub wiki of this repository (pages use wiki links, `[[Label|Page]]`, which GitHub renders only in the wiki). To publish: create the first page of the wiki in the GitHub web interface once, then push this folder's files (without this README) to the wiki repository `<repository>.wiki.git`.

Keep these pages short and in step with `docs/status.md` and `docs/SUITE.md`; they summarize, the docs are the authority.
